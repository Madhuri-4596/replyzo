# Replyzo

Single-file landing page for a managed WhatsApp follow-up service in India.

## Local review

Run `python -m http.server 8080 --bind 127.0.0.1` from this directory, then visit http://127.0.0.1:8080.

## Before public launch

1. Configure an HTTPS hosting URL or custom domain. Add the final canonical URL and og:url to index.html, plus domain-specific robots.txt and sitemap.xml on the host. A GitHub source repository is not a verified live deployment.
2. Enable host compression and caching. Python http.server is for local preview only; it does not provide production compression or security headers.
3. Verify the public URL and submit it in Google Search Console. Local SEO checks do not establish indexing or rankings.
4. Review service scope, taxes, platform charges, integrations and written commercial terms. Sample reports and conversations are illustrative.
5. Add an approved social image if required. Sharing metadata currently provides text only.

No forms, analytics or advertising trackers are installed. Google Fonts is an external request; theme preference is stored locally. Keep privacy wording current if integrations change.
